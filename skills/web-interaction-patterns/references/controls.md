# 控件与输入

| 场景 | 实现决策 | 怎么验 |
|---|---|---|
| 普通按钮 | 默认保留原生激活行为。键盘用户应看得见焦点；视觉上区分按钮按下、持续开启、当前选中和键盘焦点。使用 `:focus-visible` 或组件库处理输入方式。不在全局点击处理器里统一 blur 或禁用 outline。 | 用鼠标点一次，再以 Tab 到达同一按钮；Space / Enter 各触发一次。切换按钮的开启态在焦点移走后仍可识别。 |
| 连续操作的工具栏 | 先判断工具执行后是否继续操作内容。需要连续编辑时，可把焦点还给原画布或编辑区并保留选区、视口。工具若打开设置、搜索或确认对话框，把输入交给新界面。保留键盘进出工具栏的路径。 | 点一次标记，直接按方向键；再用键盘打开设置，验证方向键只操作设置控件。 |
| 重渲染或删除 | 保留同一逻辑控件。元素已移除时，键盘操作应有合理落点，比如同一列下一行的按钮，最后一行删除后回到列表入口。异步完成时先检查用户是否已移动焦点。 | 在列表中间及末尾分别用键盘删除一项，接着按 Tab；慢请求期间先去编辑另一项，原请求结束后仍可继续输入。 |
| 值选择或动作菜单 | 选择字段值优先用有标签的原生 select；需要输入搜索时用 combobox；“重命名、归档”这类操作才考虑菜单。同样的向下箭头可对应三种行为。自定义控件沿所选模式提供名称、展开状态、键盘移动、提交和取消。 | 用键盘打开、浏览、提交，再打开并 Esc 取消；核对实际值与播报状态。输入中文时，确认候选词的回车不能顺带提交业务表单。 |
| 输入与快捷键 | 单行字段、普通多行文本和编辑器有不同的 Enter 语义。优先使用原生表单提交。让文本编辑、组合输入和打开的弹层优先处理按键，再在对应工作区解释快捷键。单字符快捷键应按适用条件支持关闭、重映射或限制焦点范围。 | 输入含空格和快捷键字母的文本，按左右键移动光标，中文选词后再提交；确认没有触发播放、翻页或重复保存。 |
| 模态对话框 | 打开后将焦点放到适合阅读或操作的位置，背景不可交互，Tab 在框内循环；提供明确关闭入口并支持 Esc。长篇内容可先聚焦标题，难撤销的确认可优先聚焦安全选项。关闭后通常回到触发者；触发者已消失或下一步明确时选合理落点。 | 连续测试 Tab、Shift+Tab、Esc 和关闭按钮；有未保存输入时走一次既定取消策略。普通非模态浮层无需照搬模态焦点陷阱。 |
| 标签页 | 横向标签通常以左右键移动。内容预载、切换即时可随焦点激活；需明显等待时，可让方向键只浏览标签，按 Enter / Space 再加载。 | 用方向键依次浏览三个标签，确认慢加载不会造成焦点回跳或旧内容覆盖新页。 |
| 触屏与拖拽 | 关键操作应能通过点击或键盘发现和完成。若一项功能依赖拖动，检查是否需要单指免拖动替代及标准例外，如“上移/下移”或输入区间端点。保留足够触达面积，核对目标间距与例外。 | 在窄屏不用 hover 打开操作入口，用点击完成同一结果；另用键盘完成一次。 |
